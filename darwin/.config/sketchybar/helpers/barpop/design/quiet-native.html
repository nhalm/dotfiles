Direction

Quiet Native

Control Center restraint for a black bar: one opaque card, one left edge, regular weights, and hierarchy carried by size and color alone. Every popup is assembled from the same twenty-one components and six type sizes, so a new widget is a composition, not a design job.

Signature — the anchor light. Each card’s top hairline is lit in primary exactly beneath the bar icon that opened it, fading out to either side, with a faint wash of the same color falling into the card. It draws outward from the icon on open, so the popup reads as light spilling out of the bar. The bar icon itself turns primary with a 4 pt dot, closing the loop.

Composition rules

Rule
OrderHeroHeader → sections → FooterLink. Every popup, always. EmptyState may replace HeroHeader + sections.
One left edgeAll text sits on the 20 pt content edge. Hover pills bleed out 8 pt; nothing indents.
Spacingcard padding 20 · between sections 20 · SectionLabel → content 8 · rows stack at 2 · StatTile grid gap 8 · last section → FooterLink 16.
Accent budgetaccent fill is for “on / now / current”: an on HeaderToggle, today, the now-marker, meter fill, selected tile. Never decorative.
WeightRegular everywhere. Light only for type.display. No bold, no uppercase, no letter-spaced caps.
Which listChoosable things → ListItem. Facts → ValueRow. Numbers that change → StatTile. A span of time → ArcProgress / TrendChart.
Criticalcritical appears only when the user should act (battery ≤ 20%). It never tints the whole card.
New needsA popup that needs something missing adds a generic kit component (e.g. ArcProgress, ClockFace) — no popup-local styling.

Emergence · storyboard

Borrowed from Caelestia’s drawers, told quietly: the card is not faded in, it grows out of the bar icon. One shape, one spring. The panel window is pre-sized to the final card; only the SwiftUI shape inside it morphs, so there is no window resizing.
